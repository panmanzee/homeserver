pandeploy

A small platform for hosting web apps.

Run a container or a Git repo on a single home server and get an HTTPS address at your-app.pandeploy.dev. Built and operated as a learning project.

Early access · no sign-ups yet

How it works

  1. You point the platform at a container image or a Git repository.
  2. It builds and runs the app with CPU and memory limits set by your plan.
  3. The app is reachable at its own pandeploy.dev address over HTTPS, with no ports opened on the home network.
